# MN Game — Telegram Mini App MMORPG

## Overview

MN Game is a multiplayer Telegram Mini App focused on real Ukrainian cities, property ownership, online interaction, progression systems and economy mechanics.

The project combines:

* interactive map gameplay;
* persistent online systems;
* real-estate mechanics;
* roleplay/economy elements;
* mobile-first gameplay;
* lightweight social MMO architecture.

The game is designed primarily for Telegram WebApp users with focus on accessibility and fast session gameplay.

# Real Estate System

* city-based property placement;
* admin property management;
* property statistics;
* free/busy slot tracking;
* house filtering system;

Properties are synchronized globally and displayed dynamically for all connected players.
